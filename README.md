# Sitio personal de Miguel Guevara

Sitio estático hecho con HTML y CSS, listo para publicar con GitHub Pages.

## Publicar

1. Abre **Settings** en este repositorio de GitHub.
2. En **Pages**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`, y guarda.

GitHub Pages publicará `index.html` en `https://migueljguevara.github.io/migueljguevara/`.
